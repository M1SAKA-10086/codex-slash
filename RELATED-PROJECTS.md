# Related projects

Research date: 2026-10-28. This is a public search and README comparison, not proof that no other similar repository exists.

| Project | Documented overlap | Difference from Codex Slash |
| --- | --- | --- |
| [gouthamk16/slashlight](https://github.com/gouthamk16/slashlight) | Zephyrus Slash animations, per-LED editing, CPU/memory/battery meters, media progress | Its reviewed README does not describe Codex task-progress or model/effort mapping. |
| [chaolie/CodexGlow](https://github.com/chaolie/CodexGlow) | Codex events mapped to keyboard RGB, local dashboard, OpenRGB and AULA F75 backends | Its reviewed README does not describe a dedicated ASUS Slash backend. |
| [loopbrew/codex-lamp](https://github.com/loopbrew/codex-lamp) | Codex lifecycle hooks drive lamp status and animation | Targets Moonside lamps over BLE rather than the built-in Slash bar. |
| [dpf202507/Codex-Light](https://github.com/dpf202507/Codex-Light) | Coding-agent working/waiting/done indicators | Uses a separate RP2040-Zero USB status light. |

Conclusion: similar projects exist in both Slash control and Codex status lighting. No reviewed project documented the full combination of seven-segment Codex progress length, model/effort mapping and G-Helper restoration. That combination is the proposed scope of this release, not a verified novelty claim.
